
# **Bangladesh Flag Using HTML & CSS BD**

A simple CSS practice project to create the national flag of Bangladesh using basic HTML and raw CSS.

##  About the Project

This project uses a green rectangle and a red circle to represent the national flag of Bangladesh.

##  Technologies Used

- HTML5
- Raw CSS

##  Flag Measurements

### My Practice Measurements

- Flag Width: `500px`
- Flag Height: `300px`
- Flag Ratio: `5:3`
- Circle Width: `120px`
- Circle Height: `120px`
- Circle Position: `left: 200px`, `top: 90px`

### Official Flag Proportions

For a flag measuring `500px × 300px`:

- Flag Ratio: `10:6` (equivalent to `5:3`)
- Circle Diameter: `100px`
- Circle Center: `45%` of the flag's width and `50%` of its height
- Circle Position: `left: 175px`, `top: 100px`

The official circle is positioned slightly to the left of the flag's geometric center.

## CSS Concepts Practiced

1. `width` and `height` — Define the dimensions of the flag and circle.
2. `background-color` — Adds the green background and red circle.
3. `border-radius: 50%` — Makes the red circle round.
4. `position: relative` — Sets the flag as the reference for positioning.
5. `position: absolute` — Positions the circle inside the flag.
6. `top` and `left` — Control the circle's position.
